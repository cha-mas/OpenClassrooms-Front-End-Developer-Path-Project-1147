## 🇬🇧 English Version

### About This Project
This repository contains the validated codebase for my introductory JavaScript project, designed to add dynamic interactivity to a static website for a printing company. Having extensive prior experience with JavaScript, I approached this project as an efficient execution of core programming concepts, manipulating the DOM, and implementing clean client-side logic.

### What I Did
* **DOM Manipulation & Scripting:** Programmed a fully functional, interactive image carousel from scratch, handling event listeners, slide state management, and dynamic element rendering.
* **HTML/CSS/JS Integration:** Connected custom JavaScript logic to existing static markup and stylesheets to bring the page components to life seamlessly.
* **Workflow & Version Control:** Managed code development within Visual Studio Code and tracked modifications cleanly using Git and GitHub.

### Skills & Tools Used
* **JavaScript (ES6+):** DOM selection, event handling, functions, and state control.
* **HTML5 & CSS3:** Structural DOM alignment and dynamic style modifications.
* **Visual Studio Code & Git/GitHub:** Development environment and version control tracking.

## 🇫🇷 Version Française

### À propos de ce projet
Ce dépôt contient le code validé de mon projet d'introduction au JavaScript, consistant à dynamiser le site web statique d'une imprimerie. Bénéficiant déjà d'une solide expérience préalable en JavaScript, j'ai abordé ce projet avec une maîtrise aisée des fondamentaux de la programmation, de la manipulation du DOM et de la logique interactive côté client.

### Ce que j'ai fait
* **Manipulation du DOM et Scripting :** Programmation complète d'un carrousel d'images interactif, incluant la gestion des écouteurs d'événements, le suivi de l'état des diapositives et l'affichage dynamique.
* **Intégration HTML/CSS/JS :** Connexion fluide de la logique JavaScript aux éléments statiques existants pour rendre l'interface réactive.
* **Gestion du Code :** Écriture et organisation du code via Visual Studio Code avec un suivi de version rigoureux sous Git et GitHub.

### Compétences et Outils Utilisés
* **JavaScript (ES6+) :** Sélection d'éléments du DOM, gestion des événements et logique applicative.
* **HTML5 & CSS3 :** Mise en correspondance structurelle et mise à jour dynamique des styles.
* **Visual Studio Code & Git/GitHub :** Environnement de développement et gestion de versions.
